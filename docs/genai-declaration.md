# Generative AI declaration

**For the Assessment 3 submission** (this page was written for Assessment 2 and
still applies: the declaration is about how the work was produced, not about
which assessment it is attached to).

The assessment brief requires **one** of the following statements to be
included in your final submission. Choose the one that is true for you, put it
on its own page near the front of your report **and** in the submission note.

---

## Update, 28 September 2026 - read this first

The Unit Assessor added two requirements during Assessment 2 that sit on top of
the statements below. They were not withdrawn, and the code, the report and the
translations in this project did not change between the two assessments, so
assume they still apply unless the A3 brief says otherwise:

1. **Use the official prompt.** A file called **AI-Assignment-Prompt** is posted
   with the report template on SIE Moodle. If you use AI in any capacity, you
   are told to use that prompt.
2. **Prove how you used it.** You must include **screenshots of your AI chat
   log** with your report, showing that you only *asked AI questions to further
   your understanding* and did **not** use AI to generate the code.

> "Failure to provide the appropriate evidence will result in a loss of marks.
> You have been warned."

**Be clear about what this means for this project.** The code, the report and
the translations here were generated by an AI assistant on request. That is
generation. A truthful chat log for this work therefore cannot show only
question-asking, and no screenshot should be arranged to suggest otherwise.

So the declaration below is necessary but not sufficient. You also need to
either:

* **rebuild the code yourself**, using AI only to ask questions, and keep that
  real log starting from the official prompt - the A2 deadline was extended to
  5 October for exactly this kind of correction, and the same work is still
  worth doing before Assessment 3 is marked; or
* **disclose the true extent of the AI use** using Option A, and be ready to
  explain every line.

The wording in Option A is deliberately open: fill the brackets with what
actually happened, not with the smallest thing you think you can get away with.

## Option A - if you DID use GenAI tools

> I acknowledge that I have used GenAI tools to complete this assessment. I used
> `<GenAI tool(s)>` to `<specific purpose(s) of using GenAI>` within the
> parameters outlined in the Assessment Brief and by the Unit Assessor.

Fill in the angle brackets with the truth. For example, if you used a chat
assistant to check your grammar and to help you lay out the report:

> I acknowledge that I have used GenAI tools to complete this assessment. I used
> ChatGPT to check the grammar and clarity of my report and to suggest a layout
> for the database diagram, within the parameters outlined in the Assessment
> Brief and by the Unit Assessor.

## What Level 2 permits for this assessment

The brief permits limited GenAI use for:

* brainstorming ideas or ideating
* checking grammar
* paraphrasing, editing tone or clarity
* formatting the document
* formatting references or citations
* designing layout templates

## What Level 2 does **not** permit

* **creating your report** with GenAI
* **generating text and/or code and copying and pasting it** into your report
  or your code

---

## Be ready to explain your use

The brief states the Unit Assessor may ask you to describe or demonstrate:

* which GenAI tools you used,
* how you used them,
* how that use complied with the guidelines.

Two practical consequences for this submission:

1. **You must be able to explain every line of the code and every paragraph of
   the report.** If you cannot, remove it or rewrite it in your own words.
2. **Keep your commit history honest.** Write the commit messages yourself and
   commit in the order you actually did the work, so the repository shows your
   real progress. The brief states that failing to show correct work progress
   will cause the assignment to fail.

A useful habit before you submit: open a file at random, close your eyes, and
explain out loud what the next ten lines do. If you cannot, go back and study
that part.
